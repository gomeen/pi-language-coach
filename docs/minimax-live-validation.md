# MiniMax 真实请求验证

日期：2026-11-07。验证对象：本扩展实际的 `loadConfig()`、`generate()` 和结构化响应校验，不是模拟服务，也不是另写的简化请求。

## 结论

**`MiniMax-M3` 在中国区 Anthropic 兼容接口通过三个固定样例，可用于 v0.1.0 测试版。**

- 接口：`https://api.minimaxi.com/anthropic/v1/messages`。
- 三次最终复测均 HTTP 200，完整英文与有效语法点均成功解析。
- 使用默认 30 秒超时，实测各请求约 1.4–1.7 秒。仅为当次观察，不是延迟承诺。
- 旧默认 `MiniMax-M3[1M]` 被服务以 HTTP 400 / invalid model 拒绝，已显式修正默认 ID 为 `MiniMax-M3`。
- 不增加运行时回退或自动去除后缀的行为。用户覆盖的模型 ID 仍原样发送。

## 凭据与请求范围

本轮专用环境变量尚未配置，经用户明确授权，临时在内存中解析现有 Pi MiniMax 凭据。使用只读认证存储，不输出或写入 key，不把 key 加入环境变量、源码或报告，也不改变扩展的专用环境变量认证方式。

只发送下方人工编写的固定测试句；没有发送本次聊天历史、文件、工具结果或项目内容。每个学习请求检查为固定教学规则加一条 user 消息，没有 tools、会话标识或之前的测试句。没有使用真实主模型对话进行测试。

## 最终样例

### 1. 中文否定与执行顺序

输入：

```text
先不要实现，只梳理目标和计划。
```

英文：

```text
Don't implement it yet; just outline the goals and plan.
```

语法：`Don't + base verb`；解释“祈使句的否定形式使用 Don't + 动词原形”。

HTTP 200；1422 ms。人工复核：保留了暂不实现、仅梳理目标和计划的限制。

### 2. 中英混合、路径与命令限制

输入：

```text
只检查 src/index.ts，不要修改代码，也不要运行 npm install。
```

英文：

```text
Only check src/index.ts. Do not modify the code, and do not run npm install.
```

语法：`Do not + base verb`；解释两个并列禁止要求中的 `modify` 与 `run` 均为原形。

HTTP 200；1582 ms。人工复核：完整保留路径、命令及两项禁止要求，没有额外的英文纠错字段。

### 3. 英文纠错与对应讲解

输入：

```text
He don't know how to fix this bug.
```

英文：

```text
He doesn't know how to fix this bug.
```

语法：`subject + doesn't + base verb`；解释“第三人称单数主语 He 后用 doesn't，且谓语动词保留原形 know”。纠错字段说明将 `don't` 改为 `doesn't`，保留 `know` 原形。

HTTP 200；1735 ms。人工复核：纠正目标错误，没有把主要动词误改为 `knows`。

## 本轮发现与修正

1. **模型标识无效。** Pi 自定义配置中的 `[1M]` 后缀不能据此推断为服务支持的模型 ID。先验证旧 ID 的真实失败，再单独显式验证 `MiniMax-M3`，没有自动切换模型掩盖失败。
2. **语法内容需要实测。** 初轮 M3 虽然纠正了 `He don't know`，但语法字段泛称动词需加 `-s`，不能准确解释助动词变化；中文翻译样例还产生了不必要的“纠错”。随后收紧规则，要求定位输入中的真实错误、明确助动词与原形动词的关系，并只在英文确有错误时给纠错字段。上面的三例来自修改后的最终复测。
3. **两行内优先显示教学内容。** 模型可能返回较长的英文引用，先显示引用会挤掉中文语法。下行改为优先显示句型与中文说明，不重复展示长英文引用；引用仍保留在结构化结果中，用于验证它确实属于当前译文。

## 验证边界

这不是大规模质量评测。三个固定样例不能证明所有翻译、语法讲解、模型输出格式或提示词注入防护都正确；教学规则也不是形式化语法验证器。未覆盖国际区账号、其他套餐/模型、长时间负载、真实账单或全平台终端。

本轮真实请求验证与之前的隔离真实 Pi / 模拟双模型测试是两种证据：前者证明当前服务与样例输出可用；后者检查主任务不阻塞、上下文/会话隔离、取消与固定行数。不能把单独模型请求当成完整真实双模型会话验收。
